Overview

Still needs changing, in order

  1. Icons: 92 emoji used as icons in 326 places. They render differently on iPhone and Android and clash with the V3 style. A painted set of about 40 covers them all.
  2. 8 bosses and the Warding Seal: one painted top-down image each; two for bosses that change form.
  3. Armory, Workshop, Faction Hall: painted 3/4-view buildings to match the Shipyard and Charm Shrine.
  4. A display font for titles and headings.
  5. Explosion, splash and smoke sprite sheets for combat.
  6. Weather overlays from the Weather V2 sheet (code work; art already supplied).
  7. UI restyle against the V3 UI style guide (CSS work, not images).
  8. Landmarks and Reef Defence towers: painted 3/4-view versions.
  9. Sound: every effect and all music is synthesised. Not art, but the same "finished" gap.

Do

  • Send newly painted art in the V3/V4 style: clean shapes, controlled shading, teal, sand and dark-blue palette.
  • Use real transparency: PNG with alpha, nothing behind the subject.
  • Paint creatures and bosses top-down, facing up or right. One image is enough; the game turns it smoothly to any angle.
  • Paint buildings, landmarks and towers in 3/4 view, lit from the top-left, like the Shipyard and Charm Shrine.
  • For ships, send a full 24-frame turn including bow-on and stern-on views. The V5 Galleon sheet is the template.
  • For icons, send a matching set on one grid (e.g. 128px each), same outline weight and lighting.
  • For effects, send frame strips (e.g. 8 frames of an explosion), evenly spaced.
  • Send one file per asset, around 256–512px, the subject filling most of the frame, named after the game id (e.g. enemy-caldera_wyrm.png).

Don't

  • Don't send exports or screenshots of the current game art. Most of the V5 assets/ folder was this, so it changed nothing.
  • Don't pre-rotate sprites into 8 directions. The game rotates smoothly, and fixed steps look worse.
  • Don't bake in shadows, water, glows, backgrounds or labels. The game draws its own, and baked edges leave coloured fringes.
  • Don't send terrain as island tiles. Levels are generated from a shape; send colour and texture direction instead.
  • Don't use painterly concept art for gameplay sprites. It doesn't read at phone size.
  • Don't put text in images. All UI text is live.
  • Don't send sheets with overlapping or unevenly spaced frames.

Also checked, nothing needed

  • App icon: your own art, already in.
  • Liveries: recolours of the painted ships, so they follow any new ship art automatically.
  • Bestiary: shows each enemy's in-game art, so it improves as sprites land.
  • Darkness, lantern light, vignette, lighthouse beam: lighting, not objects. Keep as code.
  • Chart sea and routes, loading bar, tutorial arrows: covered by the UI restyle.
  • Old maze-mode art (exits, lair currents): no longer used in play.
