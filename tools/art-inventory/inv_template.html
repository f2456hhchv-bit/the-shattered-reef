Shattered Reef Art Inventory

Every piece of art in the game, checked against the new standard: the toy-render ships. Each asset shows how it draws in the game today, its style (toy, older painted, or code) and how urgently it needs restyling. The prompt kit below is everything you need to brief ChatGPT, in one place.

Overview

The standard

A smooth 3D toy, like a plastic board-game piece. Rounded chunky shapes, matte colours, soft light from the top-left. Four main colours at most. No scales, rivets, cracks, patterns, text or surface texture. Smooth, not faceted. It must read at 64px on a phone.

The 7 player ships set this standard. Every new asset is briefed with one of them attached. Never use the word "painted" in a prompt: it pulls ChatGPT back to the old illustrated look.

Restyle priority, in order

  1. Bosses (batch A) ✓ done 2026-10-08: all ten bosses and the Warding Seal.
  2. Creatures (batch G) ✓ done 2026-10-07: every regular creature, stages 2-10.
  3. Harbour buildings (batch B1-B6): all six together. It's the first screen, and three painted plus three code buildings don't read as one set.
  4. Weapon and upgrade icons (batches D, E): they replace emoji on the level-up cards, which are seen dozens of times a level.
  5. Pickups (batch C): sea glass and coins are on screen all the time.
  6. Reef Defence towers (B7-B13) and landmarks (batch F).
  7. Then the non-sprite gaps: a display font, explosion and splash sheets, weather overlays, a UI restyle, recorded sound.

Do

  • Attach an approved toy ship image to every request. The style follows the picture far more than the words.
  • Ask for one asset per message, on a transparent background (flat #FF00FF magenta if it can't).
  • TOP view for anything that swims or flies: straight down, front pointing to the top of the image. The game turns it to any heading.
  • FRONT view for upright things (golems, sirens, buildings, towers, landmarks, pickups, icons): front three-quarter, slightly from above. The game mirrors it left and right.
  • Ships only: one image with 5 views in a row (see the prompt kit).
  • Fill most of the frame; around 1024px is fine. The game trims and scales it.

Don't

  • Don't accept painterly, textured or detailed results. Reply with the fix line below rather than starting again.
  • Don't send 24-frame turn sheets. They came back mostly stern-side and unusable; the 5-view set works.
  • Don't send 8-direction pre-rotations, or re-renders of the game's current art. Both changed nothing last time.
  • Don't bake in shadows, water, glows or text. The game draws its own.
  • Don't send terrain tiles. Levels are generated, so terrain stays code.

When ChatGPT drifts

  • It holds the style for 3-4 images, then slips. Start a fresh chat every batch, or every 3-4 images.
  • If it writes code or describes the image instead of making it, start a fresh chat. Arguing doesn't fix it.
  • Too busy? Reply: Too many parts. Remove [X]. Keep everything else identical.
  • Too detailed or textured? Reply: Simpler. Smooth plastic toy, no texture, fewer details. Same pose.
  • The header makes it restate the asset, view and style before each image. If that line is missing or wrong, the image will be too.
