SHATTERED REEF — V3 ART ASSET PACK

This package retains the original Shattered Reef asset structure and includes the new V3 visual direction supplied as the approved reference.

V3 scope:
- Home Screen / hub refresh
- Terrain and multi-biome island direction
- Rocks and reefs across biomes
- Player ships
- Environment props
- Buildings / landmarks
- Enemies by biome
- Boss redesign direction
- Top bars / HUD
- Buttons and panels
- Dialogue / text boxes
- Resource / item / state icons

The V3 master sheet is a visual source-of-truth reference. Existing assets remain included so implementation can be performed without losing the original pack.

IMPORTANT ART DIRECTION:
- Simple, clean 2D game assets
- Strong readable silhouettes
- Controlled detail
- Soft colour blocks and restrained highlights
- No photorealism
- No painterly rendering
- No excessive 3D detail
- Consistent Shattered Reef palette and proportions
- Bosses receive a stronger silhouette/character redesign without becoming over-detailed
