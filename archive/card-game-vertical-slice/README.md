# Archived: card-game vertical slice

This was The Shattered Reef's original concept — a Hearthstone Battlegrounds-
style auto-battler. Steps 1-6 of its 8-step build order were completed and
fully tested (78/78 tests passing) before the project pivoted.

**Why archived (2026-09-28):** after playtesting the step-6 vertical slice,
the project owner judged that a solo auto-battler against heuristic AI can't
realistically compete with Hearthstone Battlegrounds' years of live balance
and human-opponent texture — a structural ceiling, not a polish problem.
The repo and name "The Shattered Reef" were kept, but the game itself was
replaced with a nautical maze-battler (see the root CLAUDE.md).

Nothing here is wired into the current build. Kept for reference / in case
individual pieces (the data-driven content pattern, the touch drag-drop
code, the AI-tuning-as-data approach) are useful again later.
